# Larp Exodus Wallet iOS App Clone — Crypto Wallet UI Demo

An **unofficial Exodus-style wallet app simulation for iPhone** from Larp Apps. It presents a connected crypto portfolio, asset-management screens, activity details, and a Web3 browser interface for fictional walkthroughs. Configurable balances and transaction views are display content, not proof of holdings or a completed blockchain transfer.
